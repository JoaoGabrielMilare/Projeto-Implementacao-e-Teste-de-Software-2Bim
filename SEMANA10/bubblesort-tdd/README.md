# Bubble Sort com TDD

Ordenação de um vetor de inteiros em ordem crescente. O método `ordenar()` compara os elementos vizinhos e troca os que estiverem fora de ordem. Se uma passagem não realizar nenhuma troca, a ordenação é encerrada.

Os três testes fornecidos foram mantidos. Os testes adicionais verificam vetor vazio, um único elemento, números negativos e os limites de `int`.

## Como executar

Com JDK 17 ou superior e Maven instalados, execute nesta pasta:

```bash
mvn test
